# 土增稅神器｜台灣不動產稅務試算工具

免費、免登入的台灣不動產稅務線上試算工具與知識庫。
線上使用：**<https://calc.zengzhisui.com/>**

土地增值稅的計算牽涉公告現值、前次移轉現值、物價指數調整、三級累進稅率、長期持有減徵與自用住宅面積分段，一般民眾很難自己算對；而賣一間房通常同時遇到土增稅與房地合一稅兩種稅。這個專案把這些計算做成可以直接用的工具，並把每一項的法條依據寫清楚。

## 計算依據

平均地權條例第 33 條；土地稅法第 28、31、32、33、34、34-1、35、39、39-1 條；
所得稅法第 4 條之 4、第 4 條之 5、第 14 條之 4、第 14 條之 5；
遺產及贈與稅法第 19、20、21、22、24 條；契稅條例第 2、3、13、16 條。

物價指數採稅捐稽徵機關適用之消費者物價總指數。稅率級距與免稅額依法逐年公告調整，程式以年度參數表管理，不寫死於程式碼。

## 技術

純靜態網頁，無前端框架、無建置流程。計算全部在瀏覽器本機完成，**使用者輸入的數值不會傳送到伺服器、不會留存**。

- `web_app/calc.js` — 土增稅計算引擎
- `web_app/cpi.js` — 物價指數資料
- `web_app/tools/` — 各稅目試算工具
- `web_app/articles/` — 文章
- `ops/` — 站台維運腳本（sitemap、內部連結稽核、法遵掃描、測試）

執行測試：

```bash
node ops/test_tax_tools.mjs      # 用官方公開範例驗算稅率與級距
node ops/verify_articles.mjs     # 法遵禁用詞、canonical、H1、死連結掃描
node ops/link_audit.mjs          # 內部連結結構稽核
```
